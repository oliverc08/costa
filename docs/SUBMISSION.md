## Project facts judges can verify

Costa is a multilingual web app that helps people navigate Medi-Cal and related benefits, understand benefit letters, save next steps on their device, and find local help. The default Ask experience uses a multilingual FAQ and deterministic local agent over curated sources. Eligibility screening uses TypeScript rules. The default run does not call a cloud model or AI Gateway.

- Live demo: https://costa-five.vercel.app
- Judge walkthrough: https://costa-five.vercel.app/how
- Public source repository: https://github.com/oliverc08/costa
- Runtime and development-assistance disclosure: [AI-DISCLOSURE.md](./AI-DISCLOSURE.md)
- Local setup: [SETUP.md](./SETUP.md)

The app covers Medi-Cal, CalFresh, WIC, CalEITC, and disaster-aid information in seven languages. Screening is informational; Costa does not determine eligibility or award benefits.

## Suggested application workflow

1. Confirm each entrant's eligibility and complete the portal profile with a personal email and required guardian details.
2. Read the current rulebook and the district's instructions. Confirm the live deadline.
3. Test the app on the device and network you will use for the video. See [DEMO.md](./DEMO.md).
4. Review and personalize the draft in [APPLICATION.md](./APPLICATION.md). Replace every bracketed field and remove claims the team cannot support.
5. Review [AI-DISCLOSURE.md](./AI-DISCLOSURE.md) with each participant. Add any tools or contributions missing from it.
6. Record the public 1–3 minute video if that remains the portal requirement. Include the real names of participants, app name, purpose, audience, tools/languages, and live app demonstration as directed by the current instructions.
7. Add the correct video and source links in the portal, submit, and save the confirmation.
8. Complete any post-deadline questionnaire required by the rules.
